WordDuelWordDuel 拼词对战

Real-time multiplayer spelling competition game for students, aligned to the Australian Curriculum (Foundation–Year 12+). Features live competition rooms, TTS audio, 12 difficulty levels, personalised word selection, and a leaderboard. Role: Product Owner — all requirements, game mechanics, scoring rules, and roadmap were defined by me. The entire codebase was built by AI (Claude Code); no code was written by hand.
